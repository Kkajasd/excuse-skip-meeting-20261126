Entry for [The Funniest Excuse for Skipping a Meeting](https://make.fun/competitions/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163) on make.fun.

One razor-sharp line, 200 characters or fewer, that gets you out of a pointless
work meeting or Zoom call. An AI judge pairs excuses head to head and keeps the
sharper, more relatable laugh.

## Entry

> Sorry — I can't make it. I've read the agenda, and my absence is the most
> productive thing I'll contribute today.

## How it works

`main.ts` (Node.js stdlib only, no dependencies) writes the line to
`/output/entry.txt`. Run it with:

```sh
node main.ts
```
